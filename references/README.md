# Theory references for cohesion EN–VI

These digests exist so an annotator makes the **same category decision for the
same reason** every time. Read the one that matches the question before writing a
tie; the tie table is the audit trail, and the analysis file must show the
decision, not just the label.

| File | Source | Use it for |
|---|---|---|
| `halliday-hasan-1976.md` | Halliday & Hasan, *Cohesion in English* (Longman, 1976) | English categories: reference, substitution, ellipsis, conjunction, lexical cohesion; the tie tests |
| `tran-ngoc-them-2006.md` | Trần Ngọc Thêm, *Hệ thống liên kết văn bản tiếng Việt* (NXB Giáo dục; 1st ed. 1985, 3rd ed. 2006) | Vietnamese categories, utterance types, formal vs content cohesion, zero anaphora (*thế đại từ khiếm diện*) |
| `translation-en-vi-2020.md` | Nguyễn Thanh Tùng, HCMUE Journal of Science 17(2), 2020, 305–320 | What actually shifts in EN↔VI translation; which devices cause difficulty |
| `en-vi-mapping.md` | This skill (synthesis) | One category per form: decision tests and the warnings that prevent double coding |

## How these were produced

- Halliday & Hasan: the scanned PDF has no text layer. The table of contents and
  the opening of Chapter 1 were OCR'd (Tesseract, `eng`); chapter and section
  numbers below come from that OCR. The digests paraphrase the framework and do
  **not** reproduce the book's examples or long passages.
- Trần Ngọc Thêm: the Internet Archive scan has an OCR text layer. Chapter and
  section numbers were checked against the printed table of contents
  (`Mục lục`); quotations are limited to short technical terms.
- Nguyễn Thanh Tùng (2020): a born-digital text layer. The reported figures and
  contrastive observations are taken from §§2–4 of the article.
- No PDF is redistributed with this repository. Page/section anchors are given so
  a reader can verify a claim in the original.

## Rule of use

1. A reference digest may **explain** a category; it may not invent a tie.
2. When the English and Vietnamese frameworks disagree about the same surface
   form (the typical case is a zero subject), record both readings in the
   analysis and keep **one** code in the tie table, following §2.4 of `SKILL.md`.
3. If a decision is not covered here, write the doubt in the analysis file
   (`conf: low` plus a note) instead of guessing silently.
